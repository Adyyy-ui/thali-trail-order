# Thali Trail Order

Build a premium, modern restaurant QR ordering website called DineFlow.

Create a beautiful mobile-friendly food menu with a black and gold theme. Include food categories, food images, Indian prices, Add to Cart buttons, quantity controls, a shopping cart, subtotal, total, and a checkout page.

Use React and TypeScript. Add realistic sample food items. Make all buttons functional and ensure the design works perfectly on Android phones and desktops.

I am a complete beginner. Build the frontend first using sample data. Do not require a database, login, or payment gateway yet. Make it easy to preview and test.
